Quick start & export notes

Tap or drag over steps to toggle them. Double-tap a step to clear it. Each step changes only once per swipe. Shift-click cycles velocity (Normal → Accent → Soft → Off). Scroll horizontally using the scrollbar below the grid. S solos a track; voice names mute. Track length creates independent loops. Synth notes use the track's note selector. Your session saves on this device automatically. Share links contain the full pattern. WAV exports one master loop with an effects tail; independent track cycles may continue beyond that loop. MP3 is not exported: WAV is lossless and can be converted in your audio editor. Start playback to enable audio. Playback pauses when this tab is hidden.
